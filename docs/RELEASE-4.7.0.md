# v4.7.0 更新日志（2026-11-15）

> 4.6.0 → 4.7.0。这一版给养成系统加了**成长线**：干活和玩耍都会攒经验，等级到了
> 她会**自己学会技能**——没钱自己去打工、缺东西自己跑杂货铺。
> 同时修掉一个真 bug：**对话里的状态从来没进过提示词**（经典聊天窗与气泡对话漏注入）。
>
> 版本号按语义化取 **minor**（4.7.0）：纯新增能力，存档向后兼容（旧档缺的键按默认值补齐）。

## 一句话上手

右键桌宠 → 「嘟嘟的生活」→ 顶部多了一条 **Lv./经验** 进度条，底部多了**技能**分组
（含"自主技能"开关）；打一份工或玩一次，回面板就能看到经验涨。

## 一、经验与等级

| 来源 | 经验 |
| --- | --- |
| 基础打字（+8 币） | +6 |
| AI 编程助手（+20 币） | +12 |
| 直播大肥鲸表演（+30 币） | +14 |
| 研究狭义相对论（+45 币） | +20 |
| 深海大冒险 / 练习拍地 | +3 |
| 追逐光点 | +2 |

- **玩耍给得明显少于工作**：同一个动作里"玩"不该比"干活"更划算。
- **中断不结算 = 不给经验**：`cancel_job` 一分钱一分经验都不给，堵死"开了就关"刷经验。
- 等级表是 `pet_life_data.LEVEL_THRESHOLDS`（累计经验）：Lv2 40、Lv3 100、Lv4 180、
  Lv5 280、Lv6 400、Lv7 540、Lv8 700、Lv9 880、Lv10 1080。满级 10 级。
- **只存 `xp`，等级一律派生**（`level_for`）：两个字段各自落盘迟早不同步，
  而"等级和经验对不上"是最难查的那种错。

## 二、技能（等级自动解锁）

| 技能 | 解锁 | 行为 |
| --- | --- | --- |
| 自己打工 | Lv3 | 嘟嘟币 < 20 时，自己在心跳里接一份**做得动**的最高收入工作 |
| 自己买东西 | Lv5 | 健康 < 40 / 口渴 < 25 / 饥饿 < 25 时，自己买最对症且买得起的商品 |

安全阀（都在数据表里可调）：

- 打工只在**缺钱**时触发，且要求精力 ≥ 25、距上次自主行为 ≥ 10 分钟；
  挑活时给精力留 5 点余量（耗完还剩 5 才算做得动）。
- 购物要求钱够，且距上次 ≥ 20 分钟。
- 睡觉、正在干活、养成关闭时一律不动；**一拍最多动一次**（又买又打工会让数值与气泡一起乱跳）。
- 面板上有 **「自主技能」开关**（`pet_life.autonomy`，默认开）：她替你花钱这件事
  必须有否决权。

## 三、修掉的 bug：对话里看不到状态

**现象**：精力 25（面板写着"有点困"），问她困不困，她答"不困"。

**根因**：v4.6.0 的状态注入只写在新版聊天窗 `pet/chat/widgets.py` 里，
而 `chat_ui_style = "classic"` 的用户走的是 `pet/chat/legacy_widgets.py`，
气泡快速对话走的是 `pet/quick_chat.py` —— 这两处 `build_messages(...)` 根本没传
`pet_status_text`。**注入代码一次都没跑到**。

**修法**：

1. 新增 `pet/chat/pet_status.py`，三处聊天面共用同一份取法（以后不会再漏一处）。
2. `PetLifeService` 每拍把状态同步进 config 的**内存**（`_sync_memory`），
   写盘仍按指纹节流。之前 `set()` 和 `save()` 绑在一起，聊天侧拿到的是上次落盘的值。
3. 注入段补一条**硬规则**：
   「被问到困不困、累不累、饿不饿、渴不渴、心情怎么样时，必须照上面的档位如实回答
   （精力 25 就是「有点困」），不许说反话，也不许用「我很好」盖过去。」
   少了这条，模型会照人设硬撑。

## 四、注入段现在长什么样

```
【嘟嘟当前状态】饥饿 80/100（吃饱了）、口渴 80/100（喝足了）、心情 90/100（心情很好）、
精力 25/100（有点困）、健康 100/100（很健康）、嘟嘟币 100。
【等级与技能】Lv.3（本级 20/80 经验）；已掌握的自主技能：自己打工。
【表达要求】被问到困不困、累不累……必须照上面的档位如实回答……；她有点困：回话比平时短一点、语气软一点。
```

**契约不变**：养成关掉 / 状态读不到 → 空串 → 提示词与"没有养成系统"时**逐字节一致**。

## 五、界面

- **面板**：顶部 Lv. + 经验进度条（本级 x/y，满级显示"已满级"）；工作/玩耍行标注 `+N 经验`；
  新增「技能」分组（已学会 / 未解锁）与「自主技能」开关；状态行前面加了 `Lv.N`。
- **状态条**：底行变成 `Lv.N　嘟嘟币 X`（`level=0` 时不显示，老调用面不受影响）。
- **升级 / 学会技能**：冒泡 + 播动画（升级播玩耍动作，"自己打工"解锁播工作动作）。

## 六、测试

技能解锁与"只播报一次"、自主打工/购物的全部前置条件、`normalize` 新键兜底、
注入文案里的等级与硬规则、三处聊天面都注入状态段。

`tests/test_pet_life.py` 原有 40 项继续通过（`prompt_text` 里多了等级段与硬规则，
