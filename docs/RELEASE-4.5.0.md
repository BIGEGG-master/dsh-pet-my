# v4.5.0 更新日志（2026-11-12）

> 4.4.1 → 4.5.0。这一版只有「让她记住」这一件事：**记忆卡**（照片与文字，带她写的
> 备注）与**嘟嘟的日记**（每天的对话，像日记一样写下来，可按时间/按词回看），
> 外加内置的「嘟嘟」角色卡。
>
> 版本号按语义化取 **minor**（4.5.0）：功能新增，不改存储格式、不迁移旧配置。

## 新增

### 1. 右键「查看记忆卡」

- 存**文字**与**照片**两类卡，每张卡带一句备注；照片会复制进配置目录
  （`<配置目录>/memory-cards/photos/`），用户的原图一个字节都不动。
- **发图即入卡**：在聊天窗口里发图片（选择文件 / 拖入 / Ctrl+V 粘贴截图）时，
  图会在消息发出去之前先复制进记忆卡。
- **备注是她写的**：这一轮回复完成后，后台用同一张图与那一轮对话问一次模型，
  让她用第一人称写一句（例：「哥哥画的鲸鱼」），写回卡片。
  - 模型不支持图片 / 网络失败 / 解析不出：保留发送时用户自己那句话当备注，
    卡片照常可用，只写日志不打扰。
  - 同一张卡 10 分钟内不重复生成备注（重发同一张图不再花一次钱）。
- 面板里能做的事：搜索（备注 + 正文）、只看文字 / 只看照片、双击看大图或全文、
  改备注、删卡（照片副本一起删）、手动「写一条」。
- 上限：500 张卡、单条正文 2000 字、备注 80 字、单图 20MB。超限时**拒绝并说明**，
  不静默丢弃。

### 2. 右键「嘟嘟的日记」

- 把 `<配置目录>/sessions/<角色>/*.json` 里的**真实对话**按天编成一篇日记：
  当天几次、起止时间、按时间引用几句原话、一共说了几句。
- **只写发生过的事**：正文完全由真实消息与时间拼成，没有发生的内容一个字都不写；
  语气是她的（每段最多一个「嘟」）。
- 左侧按天列（显示「几次 · 起止时间」），右侧是那天的日记；
  顶部搜索框**跨全部天数**找一句话，点命中直接跳到那天；
  范围可选「全部 / 最近 7 天 / 30 天 / 90 天」。
- 「导出这一天」写成 `.txt`（UTF-8 with BOM，Windows 记事本双击不乱码）。
- 全程只读会话文件，不产生第二份数据、不迁移、不删除。

### 3. 内置角色卡「嘟嘟」

- `pet/persona_cards/builtin/dudu.json`（30 组事件台词、90 条、含人设与显示名）。
- 设置 → AI → 角色卡里可以直接选「嘟嘟」；素材仍复用同一只桌宠。

## 变更

- 默认右键菜单在「AI 对话」下新增两项：「查看记忆卡」「嘟嘟的日记」。
  老用户的**自定义菜单布局会自动并入**这两项（按模板里的相邻位置插入），
  不会打乱自己排过的顺序；不想要的话在菜单编辑器里取消勾选即可。
- 两项归在 `chat` 功能模块下：停用「AI 对话」时它们一起从菜单消失
  （没有聊天数据时它们确实没东西可看）。

## 升级说明

- **不动旧数据**：记忆卡是新目录；日记是从会话文件现算的，不写盘第二份。
- 第一次打开「查看记忆卡」是空的，发一张图或点「写一条」就会出现；
  日记会直接显示历史上所有聊过的日子。
- 备注由模型生成，需要当前 provider 支持图片输入；不支持时备注就是你自己那句话。

## 已知限制

- 日记正文是**本地拼装**的（读原文 + 时间），不是让模型重写一遍——这样不花钱、
  不联网、也不会编造。想更像文章可以自己导出 txt 再润色。
- 记忆卡按「谁发的」不区分角色：多角色共用同一个数据目录时，卡片是共用的
  （与 `sessions/<角色>/` 的隔离口径不同，后续需要时再加角色字段）。
- 照片备注每次最多处理这一轮的图片（一次发送的多张图各写一句）。
