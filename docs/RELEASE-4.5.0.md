# v4.5.0 更新日志（2026-11-12）

> 4.4.1 → 4.5.0。这一版是「她能自己记住东西」：**记忆卡**（深层记忆的可视面 +
> 照片附件）与**嘟嘟的日记**（每天的对话，像日记一样写下来），外加内置的
> 「嘟嘟」角色卡。
>
> 版本号按语义化取 **minor**（4.5.0）：功能新增，不改记忆/会话的存储格式。

## 设计红线：记忆卡不是第二套记忆

**底层完全是原来的记忆模块**（`pet/chat/memory.py`）：条目、层
（`user/fact/lesson/topic`）、`hits`、归档、限额、注入逻辑一个字都没改。

记忆卡（`pet/memory_card.py`）只是它的**视图 + 照片附件**：

| 面板上看到 | 来自 |
| --- | --- |
| 一条条记忆 | `sessions/<角色>/memory.json` 里的条目（`ChatMemory.load()`） |
| 偏好 / 事实 / 教训 / 话题 | 条目自己的 `layer` 字段 |
| 「命中 N 次」 | 条目自己的 `hits` |
| 照片 | 条目的 `photo` 字段 + 同目录 `memory-photos/<条目 id>.<后缀>` |
| 删掉一条 | `ChatMemory.remove(条目 id)` ——记忆文件真的少一条 |

没有自己的索引、没有第二条写入路径、没有额外的"同步"步骤：面板每次打开直接读
那份 `memory.json`，看到的就是聊天时会被注入的那一份。

## 新增

### 1. 右键「查看记忆卡」

- **谁决定记住什么**：她自己。每轮对话后的自动提炼（`pet/chat/memory_extract.py`）
  分析这段对话值不值得记、要不要改旧条目，输出的 ADD / UPDATE / FORGET 直接落
  `memory.json`；面板只是把结果摊开给你看。
- **照片也一样**：发图时先把图复制进 `memory-photos/pending/`（粘贴图发送后就会
  被系统清理，必须先留一份），回复完成后她判断这张图值不值得记
  （`pet/chat/photo_memory.py`）：
  - 值得 → 在记忆里 ADD 一条 `layer=topic` 的条目（正文就是她写的那句备注，
    如「哥哥画的鲸鱼」），图挪进 `memory-photos/<条目 id>.png` 挂在这条记忆上；
  - 不值得（随手截图 / 表情包 / 测试图）→ 删掉暂存副本，记忆里什么都不留。
  - 判断请求失败 → **保守保留**（图是你明确发来的，宁可多记一条），备注用你
    当时那句话。
- 面板能做的事：搜正文、按层筛选（偏好/事实/教训/话题）、双击看全文或大图、
  删掉一条（等于让她忘掉，会二次确认）。
- 注：记忆卡**没有**「手动写一条」——记忆由她的判断产生，不是手写面板。

### 2. 右键「嘟嘟的日记」

- 把 `<配置目录>/sessions/<角色>/*.json` 里的真实对话按天编成日记：当天几次、
  起止时间、按时间引用几句原话、一共几句。
- **只写发生过的事**：正文完全由真实消息与时间拼成；语气是她的（每段最多一个「嘟」）。
- 左侧按天列，右侧正文；顶部搜索跨全部天数找一句话，点命中跳到那天；
  范围可选全部 / 近 7 / 30 / 90 天；「导出这一天」写成 txt（UTF-8 BOM）。
- 只读会话文件，不产生第二份数据。

### 3. 内置角色卡「嘟嘟」

- `pet/persona_cards/builtin/dudu.json`（30 组事件台词、含人设与显示名）。
- 设置 → AI → 角色卡里可直接选「嘟嘟」；素材复用同一只桌宠。

## 变更

- 默认右键菜单在「AI 对话」下新增「查看记忆卡」「嘟嘟的日记」；老用户的自定义
  布局会自动并入这两项（按模板相邻位置插入），不想要可在菜单编辑器取消勾选。
- 两项归在 `chat` 功能模块下：停用「AI 对话」时一起消失（没有聊天数据可看）。

## 升级说明

- **不动旧数据**：记忆、会话、配置的格式都没变；照片只在新发图时产生。
- 第一次打开「查看记忆卡」看到的就是你已有的记忆条目（层与命中次数都在）；
  日记会直接显示历史上聊过的日子。
- 照片记忆需要当前 provider 支持图片输入；不支持时那次判断会失败，按保守策略
  仍然记下（备注用你的原话）。

## 已知限制

- 日记正文是**本地拼装**的（读原文 + 时间），不是让模型重写——不花钱、不联网、
  不会编造；想更像文章可以导出 txt 再润色。
- 记忆卡跨角色聚合显示（多角色时按「最近创建」混排）；记忆本身仍是按角色隔离的。
- 照片判断一次最多处理这一轮的前 4 张图（成本护栏），超出的只保留暂存判断结果
  之外的部分会被清理。
