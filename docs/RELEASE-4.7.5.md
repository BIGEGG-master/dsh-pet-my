# v4.7.5 更新日志（2026-11-16）

> 4.7.4 → 4.7.5。三件事：**躺下更慢**、**醒来改伸懒腰**、**睡着时不再被别的动画顶掉**。

## 一、睡着时出现"惊恐"动画 —— 真 bug，已修

**现象**：睡着躺着，突然一脸惊恐（或被吓一跳的姿势）。

**根因**：`hold` 闸门只挡在 `_roll_next`（掷骰链）这一处。可睡着时还有一批
**绕过掷骰链**的播放入口：

| 入口 | 例子 |
| --- | --- |
| agent 联动（`agent_link`） | DSH 状态切 working/error/attention → 播对应动画 |
| 自说自话 / 主动行为 | 随机挑一段 |
| 菜单「播放动画」 | 手动点名 |

这些走的是 `BehaviorController.play_once()`，它以前没有任何常驻检查，
于是"被吓一跳"这种段就直接顶到睡着的她身上。

**修法**：`play_once(sprite, name, *, force=False)` 开头加**常驻闸门**：

```python
held = None if force else self._held_clip(sprite)
if held and name != held:
    return False
```

- 睡着时，任何非姿态段的播放请求一律拒绝（**自己那段仍允许**，否则"重新进入姿态"会被自己挡住）；
- `force=True` 只给**入睡过渡**用（它必须在常驻判据生效之后穿透进来）；
- `OverlayShell.switch_clip(..., force=)` 与 `app._pet_life_play_clip(..., force=)` 逐层透传。

## 二、醒来：直接伸懒腰

醒来不再播"起身过渡段"，改成**伸懒腰**（复用现成的 `wake` 关键词池：

```
"wake": ("超大伸懒腰", "伸懒腰")
```素材库里已有 `超大伸懒腰.webm`）。缺素材才回退到 `醒来过渡.webm`（起身段）。

## 三、躺下更慢

上一版入睡过渡只截了「变化最剧烈」的 3.2 秒 → 观感是"一下子躺下去"。
这一版用**完整变化区间**：

| 版本 | 帧数 | 时长 | 观感 |
| --- | --- | --- | --- |
| v4.7.4 | 77 | 3.2s | 太快 |
| **v4.7.5** | **158** | **6.6s** | 缓起缓落，慢慢躺 |

几何仍按"结束帧底部 92%、中心 50%"对齐，落点与常驻躺姿接得上。

## 四、最终时序

```
点「去睡觉」
  → 淡入 0.35s + 播「入睡过渡」（6.6s，倒放：坐起 → 躺下，force 穿透闸门）
  → 播完 hold 闸门自动接「睡觉-主」常驻
  → 睡着期间：任何外部播放请求被拒（不再有惊恐/被吓一跳）

点「叫醒她」
  → release_hold 摘常驻
  → 播「超大伸懒腰」
  → 播完正常掷骰回待机
```
