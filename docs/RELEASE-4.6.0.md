# v4.6.0 更新日志（2026-11-15）

> 4.5.0 → 4.6.0。这一版新增**养成系统（Pet Life）**：嘟嘟有了自己的饥饿、口渴、
> 心情、精力、健康，会饿会困会闷，能打工赚钱、去商店买吃的，还能被你一键喂饭。
>
> 版本号按语义化取 **minor**（4.6.0）：纯新增能力，不改任何既有存储格式。

## 一句话上手

右键桌宠 → **「嘟嘟的生活」** → 喂食 / 喝水 / 打开面板 / 状态条显示位置。

## 一、四层架构（为什么这么拆）

| 层 | 文件 | 职责 | 依赖 |
| --- | --- | --- | --- |
| 数据表 | `pet/pet_life_data.py` | 衰减速率、4 份工作、4 件商品、3 种玩耍、动画关键词池、阈值与台词 | 无 |
| 纯逻辑 | `pet/pet_life.py` | 夹紧、衰减、睡觉、工作结算、商店交易、注入文案、动画挑选 | 无 Qt / 无 IO |
| 运行时服务 | `pet/pet_life_service.py` | 60s 心跳、落盘、把结果发成 Qt 信号 | Qt Core |
| 呈现 | `pet/pet_life_hud.py` / `pet/pet_life_dialog.py` | 状态条 / 「嘟嘟的生活」面板 | Qt Widgets |

**分层收益**：数值平衡改 `pet_life_data.py` 一张表；规则错在 `pet_life.py` 里能
被纯函数单测当场钉住（62 项）；服务与界面都能在没有窗口的环境里构造。

## 二、五维属性

| 属性 | 每小时掉 | 作用 |
| --- | --- | --- |
| 饥饿 | −6 | 见底开始掉健康（−2/h）；< 20 会主动喊饿 |
| 口渴 | −8 | 同上；< 20 会主动要水 |
| 心情 | 不自然衰减 | 只由事件驱动（玩耍涨、被忽略掉）；< 20 会求陪 |
| 精力 | −5 | ≤ 15 自动去睡；睡觉时 +20/h；< 40 回话变短、多撒娇 |
| 健康 | 见底惩罚 | = 0 时「病倒」：工作/玩耍被拒，只有喂食喝水能救 |

**离线保护**：单次心跳最多结算 2 小时（`MAX_TICK_HOURS`）。关机一周回来不会
一开机就病倒，也不会因为"离线很久"被瞬间扣光。

**睡觉滞回**：精力 ≤ 15 入睡、≥ 70 醒，不在阈值上反复横跳。

## 三、工作 / 玩耍 / 商店

| 工作 | 收入 | 消耗 |
| --- | --- | --- |
| 基础打字 | +8 币 | 精力 −8、心情 −2 |
| AI 编程助手 | +20 币 | 精力 −15、饥饿 −6 |
| 研究狭义相对论 | +45 币 | 精力 −25、健康 −3、心情 −4 |
| 直播大肥鲸表演 | +30 币 | 心情 −12、精力 −18 |

- 每份工作 **10 分钟**，可中断；中断 = 白干（不结算，避免"开了就关"白拿钱）
- 关机期间到点的活，下次启动第一拍自动结算（`job_finished` 信号）
- 玩耍：深海大冒险（心情 +30 / 精力 −10）、练习拍地（健康 +20 / 精力 −5）、
  追逐光点（心情 +15 / 精力 −20）
- 商店：深海气泡水 10、深海蓝藻奶昔 25、鲸鱼尾巴按摩器 60、量子纠缠零食 40
  （25% 概率额外 +20 精力，一袋零食两种观测结果）
- **免费动作有冷却**：喂食 30 分钟、喝水 20 分钟——没有冷却就能无限刷，
  养成系统当场失去意义

## 四、自主生命感

服务每 60 秒检查一次，命中阈值就 **冒气泡 + 换表情**：

| 触发 | 台词（随机） | 动画关键词 |
| --- | --- | --- |
| 饥饿 < 20 | 「哥哥…嘟嘟肚子在叫了嘟。」 | 吃\* |
| 口渴 < 20 | 「好渴嘟，想喝水…」 | 吐泡泡 / 喝 |
| 精力 ≤ 15 | 「好困…嘟嘟先眯一会儿可以吗？」 | 原地小憩沉眠 / 打瞌睡 |
| 心情 < 20 | 「有点闷…哥哥陪我说说话嘛。」 | 碎碎念 |

- 同类事件 **30 分钟冷却**，不会刷屏
- 睡着了不喊饿（醒来说）
- **动画名不硬编码**：`pet_life.pick_clip` 在素材库 `acts` 里按关键词做子串匹配，
  匹配不到就静默不播——素材改名不会让功能崩溃，只是少了那一帧表演

## 五、AI 语气联动

聊天时把状态快照注入 System Prompt（`pet/chat/prompt.py`）：

```
【嘟嘟当前状态】饥饿 62/100（有点饿）、口渴 41/100（渴）、心情 78/100（还不错）、
精力 33/100（有点困）、健康 100/100（很健康）、嘟嘟币 120。
【表达要求】她有点困：回话比平时短一点、语气软一点；她饿坏了：会惦记吃的、容易分心。
不要复述这些数字，也不要解释这份状态。
```

- **空状态 = 逐字节不变**：没有养成系统（或模块停用）时，提示词与 4.5.0 完全一致
  （`tests/test_pet_life.py::test_prompt_text_empty_when_disabled` 与该一致性断言钉住）
- 状态段放在「时间感知」之后、「记忆」之前：它是**当下事实**，不该被当成记忆条目
  参与召回，也不该压在人设前面
- `ChatSettings.pet_status_text` 是**运行时字段**（`repr=False, compare=False`），
  `to_dict` 不含它 → 永不落盘、不会被设置页保存冲掉

## 六、状态条（HUD）

- 五条细进度条 + 嘟嘟币，颜色分级（≥60 绿 / ≥30 黄 / 其余红）
- 三种展示位：**跟随桌宠** / **贴在灵动岛** / **隐藏**，菜单里一键循环
- **可拖动、可贴边、悬停展开**（2026-11-15 追加）：
  - 左键按住面板任意位置拖动，松手落位；
  - 松手时离屏幕某条边 < 60px → 吸附到那条边；
  - 贴边后鼠标移开 2.5 秒 → 缩成一条 18px 细把手（三条短横线 = 可抓的暗示）；
  - 鼠标移回把手上 → 立即展开；
  - 位置（`hud_x` / `hud_y` / `hud_edge`）存在 `pet_life` 里，重开也记得；
  - 拖动过之后就不再跟随桌宠——否则刚摆好位置，桌宠一走面板又飘走了。
- 无边框置顶、不抢焦点；**会接收鼠标**（否则拖不动），覆盖处会挡住下层点击，
  拖走或菜单里切到「隐藏」即可
- **为什么不做进灵动岛里**：岛胶囊内容走 `_content_cache` 位图缓存（每秒失效重绘
  代价高）、卡片有固定四区 + 像素级高度对账、第三方段只能出文字画不了彩条。
  独立窗只需一个 `set_anchor(rect)` + 自己的拖动/贴边状态机

## 七、改动清单

**新增（5 个文件）**

- `pet/pet_life_data.py`、`pet/pet_life.py`、`pet/pet_life_service.py`
- `pet/pet_life_hud.py`、`pet/pet_life_dialog.py`

**修改（8 处）**

| 文件 | 改什么 |
| --- | --- |
| `pet/config.py` | `_initial_data()` 加 `pet_life` 默认值；`reload()` 白名单 + 归一化；`set()` 写前归一化 |
| `pet/features.py` | 新 `FeatureSpec(pet_life)`；`MIGRATION_BASELINE` 加 `pet_life`（见下） |
| `pet/context_menus/registry.py` | `pet_life` 动作 + 中文名 + 图标 |
| `pet/context_menus/shared.py` | `add_pet_life_menu()`（四项子菜单） |
| `pet/menu_templates/modern-default-v1.json` | 默认布局插 `pet_life` 节点 |
| `pet/window.py` | `PetWindow` 四个回调占位（未注入时菜单自动消失） |
| `pet/sprite_menu_facade.py` | 四个 property（overlay 拓扑的可用性判定要求） |
| `pet/app.py` | 服务懒创建 + 心跳 + HUD 轮询 + 面板 + 4 个菜单回调 + 信号接线 |
| `pet/chat/models.py` | `ChatSettings.pet_status_text` 运行时字段 |

**为什么 `pet_life` 进 `MIGRATION_BASELINE`**：基线是「老用户升级后视为已启用」的
集合，纪律是"新模块默认关"。养成系统是**用户显式要的主玩法**，不进基线等于
「做了但看不到」（菜单项与状态条都被模块门挡掉）。不想用的用户在功能页取消勾选即可。

## 八、已知限制

- **只服务主宠**：子肥鱼（多开）不建养成服务，HUD 也不跟随。每宠一份属性需要
  另做 slot 路由，v1 没做
- **HUD 用 250ms 轮询定位**：桌宠被拖到别的屏、DPR 变化时最多晚 1/4 秒跟上
- **动画依赖素材关键词**：素材库里没有「喝\*」这类动画时，喝水只弹气泡不表演
- **商店没有图标**：v1 是文字 + 强调色按钮
- **`owned` 字段预留未用**：永久解锁 / 成就是 v2
